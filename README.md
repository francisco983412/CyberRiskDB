# CyberRiskDB
CyberRiskDB es un proyecto de portafolio enfocado en el diseño y desarrollo de una base de datos para la gestión de información relacionada con la ciberseguridad.

El objetivo es construir una solución capaz de centralizar información sobre personas, activos tecnológicos, incidentes de seguridad, evidencias, vulnerabilidades, riesgos y acciones de respuesta.

El proyecto será desarrollado progresivamente, documentando las decisiones de diseño y aplicando conceptos de modelado relacional, normalización, SQL Server, consultas avanzadas, seguridad, auditoría y análisis de datos.

Más que crear una base de datos funcional, el propósito es demostrar el proceso completo de análisis, diseño, implementación y mejora de una solución orientada a un escenario real de ciberseguridad.
